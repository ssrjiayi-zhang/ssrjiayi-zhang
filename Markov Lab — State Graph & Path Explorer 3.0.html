Model assumptions and limitations

First-order Markov assumption

The current rating is treated as a sufficient summary of rating history.

Time-homogeneous transitions

The same transition matrix is used in every period.

Discrete states

Complex firm conditions are compressed into a small number of rating categories.

Simplified expected loss

ECL uses PD × LGD × EAD with constant LGD and EAD and no discounting.

Results are model-based illustrations, not causal forecasts or investment advice. Real credit migration may depend on macroeconomic conditions, rating duration, leverage, and prior downgrades.

How to use Markov Lab

1 · Choose or enter a model

Choose a preset, edit probabilities, or upload a square CSV. Values must be in [0,1] and every row must sum to 1.

2 · Explore the short run

State graph comes first, then the tree and a partial table. Counts and total probability use every path.

3 · Simulate jumps

Run a random path and adjust its speed. Each jump uses only the current-state row.

4 · Switch to the long run

Inspect first hitting time, recurrence, the 0–1 conclusion, and multi-step distributions.

5 · Corporate risk

The risk preset makes Default absorbing. Hitting time measures modeled downgrade-to-default risk.
